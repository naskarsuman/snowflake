# Foundations

These are the basic Snowflake building blocks I use before creating data pipelines.

## Topics

- Databases and schemas
- Virtual warehouses
- Roles and permissions
- Resource monitors

## Why this matters

A good setup makes the rest of the platform easier to manage. I normally separate environments and workloads so that access, performance, and cost are easier to control.

More examples will be added here as the repository grows.
